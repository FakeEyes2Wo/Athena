Athena IDE 布局方向

你已经选了更偏 VS Code / Cursor 的方向。下面是 3 种更具体的布局版本。重点看：信息密度、专业感、以及是否适合 AI4ML 工作流。

A · 经典 IDE
Explorer / Chat

经典 IDE 三栏

最像 VS Code：活动栏 + 侧边栏 + 主工作区。专业、稳定、熟悉。

B · AI IDE（推荐）
Athena Assistant

AI 优先 + IDE 工作区

左边固定聊天与任务控制，中间/右边是实验、图表、文件与 diff。最适合 Athena 的 AI4ML 场景。

C · 仪表盘优先
Left Rail

Dashboard First

更偏监控台，聊天弱化。适合盯实验，但不够像 AI IDE。

你可以直接点击一个选项，也可以在终端回复例如：B，但把聊天区再更紧凑一点。
