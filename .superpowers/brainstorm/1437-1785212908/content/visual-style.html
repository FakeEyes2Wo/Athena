视觉风格：要像哪种高级感？

目前已经确定：聊天主区 + 右侧窄仪表盘。现在定整体视觉语言，这会决定配色、边框、阴影、信息密度和“高级感”。

A · 极简高级黑
Athena

极简高级黑

像更专业的 Claude Desktop / Linear / Vercel 风格。边框细、留白多、很克制。

B · 现代 IDE 深色（推荐）
Athena Agent

现代 IDE 深色

更像 Cursor / VS Code / Raycast 的高质量融合版。专业、稳定、适合长期使用。

C · 数据产品感
Athena Console

更强的数据平台感

图表和指标更醒目，颜色更强，偏向实验控制台 / 量化面板气质。

回复示例：B、A，但不要太闷、C，不过颜色要收敛。
