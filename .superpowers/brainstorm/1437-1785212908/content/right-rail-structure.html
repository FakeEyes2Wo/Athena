右侧窄栏：里面该怎么组织？

你已经选了：聊天主区 + 右侧窄仪表盘 + 极简高级黑。最后一个关键选择是：右侧这根窄栏，到底是“固定摘要”、还是“可切换工具集”。

A · 固定摘要流（推荐）
Conversation

固定摘要流

永远显示 4 块：运行状态、SOTA/Budget、ResearchTree 摘要、最新实验。最稳定，也最不打断聊天。

B · Tab 切换工具栏
Conversation

Tab 工具集

右栏顶部有 Status / Tree / Metrics / Diff 标签。能力更强，但会频繁切换上下文。

C · 摘要 + 弹出详情
Conversation

摘要卡片 + 点击弹层

右栏只放简洁摘要；点任一块再展开浮层看 Tree / Diff / 指标详情。最克制，但交互更多一步。

回复示例：A、C，但弹层要很顺滑、B，不过默认先显示 Status。
